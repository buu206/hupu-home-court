# HUPU — HOME COURT

以 [Lando Norris 官网](https://landonorris.com/) 的镜头接力、照片档案、收藏墙与强排版为参考，制作的虎扑体育社区单页课堂作品。桌面端优先，全部交互都在当前页完成，无二级路由、无构建步骤。

## 本地预览

在项目目录打开终端运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 **http://127.0.0.1:4173**。本次已复用的现有预览地址为 **http://127.0.0.1:8080**。停止服务器按 `Control + C`。如果端口已占用，改成 `4174` 即可。

也可以直接双击 `index.html`。本地文件模式会自动保留普通图片；完整滚动叙事与浏览器存储体验推荐通过上面的 HTTP 方式查看。网站运行时不需要联网，不需要 npm install。

## 已实现体验

- **Hero**：真实关键素材加载百分比、可跳过开场；红色空心圆环 + 白色十字准星、仅平移的轻微视差；220vh 的固定滚动叙事，写真缩小/变暗，NBA × 虎扑合体登场。
- **照片叙事**：八张体育/生活照片，桌面端固定章节、纵向滚动驱动 390vw 横向空间；大/小、彩色/黑白照片混排，漂移、旋转、缩放与层次；背景从浅暖灰经过砖红到暖黑。
- **球衣档案**：16 支 NBA 球队、东西部分区；四列等宽、等间距档案墙，列内固定 ±50px 上下交替，相邻列反向起步；双层文件夹、描边、页签与切角；悬停揭示真实赛场照片，点击页内球队详情。
- **双栏**：ON COURT / IN COMMUNITY；社区侧实拍篮球训练视频按可见性自动播放/暂停，静音循环。
- **社区热点**：六条话题、五类筛选、换序、热度、页内讨论；推荐和回复在本地保存。
- **数据高光**：三组大数字滚动计数。
- **球员评分**：三场经典对阵演示；错位 3D 比赛卡入场；点击展开四张球星卡；连续大热区悬停预览（进入星星区暂停卡片倾斜）、键盘左右选择与 Enter 确认、闪光与粒子反馈、已评分状态和改分。
- **品牌与社交**：20 个尺寸与纵向位置有节奏变化的文化 Logo、行进脚本字、品牌详情；五张无边框、大圆角扇形照片、强口号页脚。

## 使用的库

- GSAP **3.13.0** + ScrollTrigger **3.13.0**：时间线、固定滚动镜头、照片漂移、入场与计数。
- Lenis **1.3.11**：桌面平滑滚动，与 GSAP ticker 同步。
- 原生 SVG + requestAnimationFrame：32px 红色圆环与白色十字准星，lerp 平滑跟随；评分卡内精确点选，不吸附、不放大。
- 原生 Canvas 2D：评分后短时粒子；无常驻粒子循环。
- 原生 `<dialog>` / `localStorage`：页内详情、本地评分、推荐与回复。

所有库、字体、图片、SVG 与视频均已本地化。人物照片来自真实素材，没有 AI 人脸。

## 数据与行为

赛程、比分、热度、社区评分与讨论均为课堂演示数据。球队内容为历史球衣与经典对阵档案，不代表实时阵容。品牌文化墙不表示真实商业合作。

评分存储键 `hupu-court-ratings-v2`，以 `比赛ID:球员ID` 隔离。讨论存储键为 `hupu-court-replies-v2`，推荐为 `hupu-court-reactions-v2`。存储被浏览器禁止时，交互仍能在本次会话使用并提示。可以在浏览器开发者工具中清理这些键来重置演示。

## 性能与降级

首屏只等待三项关键素材；档案照片延迟加载。照片经过尺寸限制和 JPEG 压缩。光标只更新位置与圆环缩放，窗口隐藏或指针离开时停止绘制；Hero 不使用 WebGL、mesh 或任何人脸像素扭曲。滚动布局刷新合并到下一帧，视频离屏暂停。系统启用“减少动态效果”时，照片段可原生横向浏览，保留内容与评分。
